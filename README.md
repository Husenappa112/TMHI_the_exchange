- Maze of Bad Habits

### Idea
- Maze of Bad Habits is an interactive, character-driven gaming experience featuring a rat protagonist.
- Players navigate challenging maze levels while avoiding enemies such as cats, dogs and ghosts.
- Players collect cheese, complete objectives and progress through increasingly challenging levels.
- The game incorporates adaptive enemy behaviour, interactive gameplay and character-based reactions.
- A player dashboard tracks completed levels, XP, rewards, achievements, scores and winning percentage.
- Player progression is stored locally to maintain game progress between sessions.

### How to Run

#### Prerequisites
- Node.js
- npm
- Git

#### Installation Steps

1. Clone the repository.
2. Navigate to the project directory.
3. Install dependencies.

```bash
git clone https://github.com/Husenappa112/TMHI_the_exchange.git
cd TMHI_the_exchange
npm install
```

#### Run Locally

```bash
npm run dev
```

Open the local URL displayed in the terminal.

#### Production Build

```bash
npm run build
```

#### Tests & Lint

```bash
npx vitest run
npm run lint
```
